# GoldBakehouse Website

GoldBakehouse is a fully functional bakery eCommerce website that allows customers to browse products, place orders, and make secure payments online.

The platform was designed and developed for a local food business to streamline online ordering and improve customer accessibility.

Live Website
https://www.goldbakehouse.com

---

## Features

• Product catalog displaying baked goods  
• Online order system  
• Secure payment integration  
• Pickup and delivery options  
• Automatic email notifications for new orders  
• Mobile responsive design  
• Customer-friendly checkout process

## Development Process

The project followed an Agile workflow:

1. Client requirement gathering
2. UI/UX prototyping using Figma
3. MVP development
4. Iterative improvements based on feedback
5. Deployment and hosting setup
